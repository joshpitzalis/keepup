# KeepUp is licensed AGPL-3.0

KeepUp's question posing and grading follow LearnHarness's `question-core.ts` (AGPL-3.0), and the author read that implementation closely, so KeepUp's version may not count as independent work. We license KeepUp AGPL-3.0 rather than waiting for permission from LearnHarness's owner. That lets work start now and keeps a later shared module licence-compatible.

## Considered Options

- **Ask LearnHarness's owner for permission first**: keeps KeepUp's licence open, but blocks coding on their answer.
- **Clean-room rewrite by someone who hasn't read LearnHarness**: no derivation question, but needs a second person and repeats work already done.

## Consequences

Relicensing later needs agreement from every contributor. Anyone who runs KeepUp as a network service must offer its source to that service's users.
